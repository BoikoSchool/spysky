Списки.

Марковані, нумеровані та вкладені. Пишемо код просто в браузері, зберігаємо комітами на GitHub і публікуємо власний сайт.

Перед початком

Створи репозиторій.

Репозиторій — це папка твого проєкту на GitHub. Усі файли сайту житимуть у ній.

  1. Увійди в GitHub

    Відкрий github.com у браузері (Safari або Chrome, не в застосунку GitHub) і увійди у свій акаунт.

  2. Новий репозиторій

    Натисни + вгорі праворуч → New repository. У полі Repository name напиши spysky.

  3. Налаштуй і створи

    Обери Public і постав галочку Add a README file. Натисни зелену кнопку Create repository.

  4. Увімкни GitHub Pages

    Settings → ліворуч Pages. У Branch обери main і / (root) → Save.

За 1–2 хвилини твій сайт з'явиться за адресою:

https://твій-логін.github.io/spysky/
Порада для планшета

Тримай планшет горизонтально. Якщо є чохол-клавіатура, підключи її, бо так зручніше набирати знаки < > /. На екранній клавіатурі вони ховаються за кнопкою 123 → #+=.

Головне вміння уроку

Що таке коміт.

Коміт — це збережена версія твоїх змін із коротким підписом. GitHub пам'ятає кожен коміт, тому завжди видно, що і коли ти змінив.

Правило гарного підпису

Пиши коротко, що саме ти зробив: «Додано список інгредієнтів», «Виправлено вкладений список». Підпис «123» або «зміни» нічого не пояснює.

Етап 1 · Знайомство з прикладом

Три теги. Три коміти.

Список у HTML складається з «коробки» (самого списку) і «речей у коробці» (пунктів). Набирай кожен приклад у своєму репозиторії і зберігай комітом.

<ul>unordered list

Маркований список. Порядок не важливий: покупки, інгредієнти, хобі.

<ol>ordered list

Нумерований список. Порядок важливий: кроки, рейтинг, розклад.

<li>list item

Один пункт списку. Живе тільки всередині ul або ol.

Крок 0. Створи файл index.html

Add file → Create new file → назва index.html. Встав каркас сторінки і зроби перший коміт. Усі приклади нижче дописуй всередину <body>.

      Екранна клавіатура «виправляє» код
      Планшет може сам ставити велику літеру чи замінювати лапки на «ялинки». Вимкни в налаштуваннях клавіатури автовиправлення та розумну пунктуацію, або перевіряй код уважно перед комітом.
